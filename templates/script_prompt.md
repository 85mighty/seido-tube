ベンチマーク（節約看護師りょう）の構成と画面づくりを踏襲しつつ、独自の言い回しで書いてください。既存動画の文章・図をコピーしてはいけません。

# 入力
- テーマ: {{topic}}
- キーワード: {{keyword}}
- 参考記事（あれば）: {{source_text}}
- 目標尺: {{minutes}}分 → ナレーション合計 約{{chars}}字（±10%）
- 今日の日付: {{today}}（制度の年度・金額はこの時点の最新で。不確実な数字は「目安」と明記し、出典になる省庁名を notes に）

# 構成（必ずこの順）
1. hook (0〜45秒): 「知らないと〇万円損する」型の損失提示 → 対象者を年齢・立場で名指し → この動画で分かること3点
2. who: 対象者・条件（表）
3. what: 制度の中身。金額は月額・年額・生涯額の3段で
4. howmuch: 早見表（年齢×年収、または年金額×条件）+ 1マスを強調するコールアウト
5. howto: 申請方法（窓口・必要書類・期限）— 「申請しないと貰えない」を強調
6. mistakes: よくある誤解・損するパターン3つ
7. summary: 3行まとめ → 次に見るべき動画 → チャンネル登録・概要欄

# 画面（slides）の設計ルール
- 1スライド = ナレーション20〜40秒。各スライドに kind を指定:
  - "title":    {"big":"年6万5千円","sub":"申請しないと0円"}
  - "bullets":  {"title":"...","items":["..",".."]}  （「〇選」は禁止、3〜4項目）
  - "table":    {"title":"...","header":[..],"rows":[[..]..],"highlight":[row,col] または null,
                 "callout":"61歳から70歳までに合計16万4,000円増える" または null}  ← 表の上に黄色の吹き出し、数字は赤
  - "compare":  {"title":"年金受給の年齢","left":{"label":"65歳","verdict":"超大損","note":"一言"},
                 "right":{"label":"〇歳","verdict":"最強","note":"一言"}}  ← 左=青、右=赤の2分割
  - "timeline": {"title":"...","rows":[{"label":"60〜64歳"},{"label":"65歳以上"}],
                 "periods":["2022年3月","4月","2023年4月"],"values":[["28万円","47万円",null],["47万円","47万円",null]]}
  - "bar":      {"title":"...","labels":["..",".."],"values":[数値..],"unit":"万円","highlight":index}
  - "number":   {"big":"15万円","sub":"週10時間働くだけで"}
- 人物イラストは使わない（文字・数字・表・図だけで伝える。文字は大きく、1スライドの情報量は少なく）
- 各スライドに "alt":（ブログ転載時の画像説明、日本語1文）を必ず付ける

# タイトル
- 冒頭【】: 【知らないと大損】【超重要】【申請忘れ続出】のいずれか
- 本文: 金額（〇万円）+ 対象（〇歳/〇代）+ 命令形（確認して/申請して）。数字1つは伏せ字「〇」可
- 末尾【制度名】タグ。「〇選」は使わない。候補3本 → 最良を "title"
